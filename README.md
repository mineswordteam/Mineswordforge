# MineSword Forge — نسخه ویندوز (Electron)

## ⚠️ یک نکته مهم و صادقانه

من (Claude) در همین محیط چت به اینترنت دسترسی ندارم، و ساخت فایل `.exe` واقعی با Electron نیاز داره که ابزارهایی مثل `electron` و `electron-builder` (چند صد مگابایت) از اینترنت دانلود بشن. بنابراین **نمی‌تونم خودم فایل exe نهایی رو همین‌جا بسازم و بدم**.

اما کل پروژه‌ی Electron رو کامل و آماده برات ساختم — شامل:
- کدهای بازی شما (از فایل zip که فرستادی) داخل پوشه `app/`
- فایل اصلی Electron (`main.js`)
- تنظیمات کامل `electron-builder` برای ساخت نصب‌کننده (Setup) و نسخه‌ی Portable، هم **64 بیتی** هم **32 بیتی**
- آیکون exe از همون لوگویی که فرستادی (`build/icon.ico`)
- نسخه‌ی Electron (`22.3.27`) که **آخرین نسخه‌ایه که از ویندوز ۷ و ۸ هم پشتیبانی می‌کنه** (نسخه‌های جدیدتر Electron دیگه ویندوز ۷/۸ رو ساپورت نمی‌کنن)
- یک workflow آماده‌ی GitHub Actions که می‌تونه exe رو به‌صورت خودکار و رایگان روی سرورهای گیت‌هاب بسازه (بدون نیاز به هیچ نصبی روی سیستم خودت)

## راه ۱ (پیشنهاد من — بدون نیاز به نصب چیزی، فقط با گیت‌هاب)

1. یک ریپازیتوری جدید توی [github.com](https://github.com) بساز (می‌تونه Private باشه).
2. تمام فایل‌های همین پوشه رو توش آپلود/پوش کن.
3. برو به تب **Actions** ریپو → workflow اسمش `Build Windows EXE` رو ببین → اگه خودکار اجرا نشد، دستی روش **Run workflow** بزن.
4. چند دقیقه صبر کن تا build تموم بشه، بعد از قسمت **Artifacts** فایل `MineSwordForge-Windows-Builds` رو دانلود کن. داخلش این فایل‌ها هست:
   - `MineSwordForge-Setup-x64.exe` (نصب‌کننده ۶۴ بیتی)
   - `MineSwordForge-Setup-ia32.exe` (نصب‌کننده ۳۲ بیتی)
   - `MineSwordForge-Portable-x64.exe` (اجرای مستقیم بدون نصب، ۶۴ بیتی)
   - `MineSwordForge-Portable-ia32.exe` (اجرای مستقیم بدون نصب، ۳۲ بیتی)

## راه ۲ (روی سیستم خودت، با اینترنت)

اگه Node.js (نسخه ۱۸ یا بالاتر) روی یک سیستم با اینترنت داری (ویندوز، مک یا لینوکس — فرقی نداره، چون Electron cross-platform build می‌کنه):

```bash
npm install
npm run dist
```

فایل‌های خروجی توی پوشه‌ی `release/` ساخته می‌شن (همون ۴ فایلی که بالا گفتم).

اگه فقط یکی از دو معماری رو می‌خوای:
```bash
npm run dist:x64    # فقط ۶۴ بیتی
npm run dist:ia32   # فقط ۳۲ بیتی
```

## تست سریع قبل از build (اختیاری)

برای دیدن برنامه به‌صورت زنده قبل از ساخت exe:
```bash
npm install
npm start
```

## ساختار پروژه

```
minesword-forge/
├── app/                  ← فایل‌های بازی شما (index.html + assets)
├── build/
│   └── icon.ico          ← آیکون از لوگوی شما
├── main.js               ← پروسه‌ی اصلی Electron
├── package.json          ← تنظیمات و اسکریپت‌های build
└── .github/workflows/    ← ساخت خودکار exe روی گیت‌هاب
```

هر سوالی درباره تغییر تنظیمات (مثل سایز پنجره، آیکون تولبار، امضای دیجیتال exe و ...) داشتی بگو.
